# Política de Segurança

Não publique vulnerabilidades de segurança em Issues públicas.

Este projeto ainda não tem um canal privado de recebimento de relatos configurado. Antes de divulgar uma vulnerabilidade, abra uma discussão privada com o mantenedor por um canal previamente acordado. Esta política será atualizada assim que um canal de contato seguro for estabelecido.

Os relatos devem incluir uma descrição do impacto, os passos para reprodução e uma possível sugestão de correção, sem expor dados sensíveis, credenciais ou sistemas de terceiros.
